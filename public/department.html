Clinical Departments Directory (DOM-based XSS)

Client-side script execution vulnerability: Untrusted URL fragments (location.hash) evaluated directly by browser DOM execution sinks.

Execution Flow: Selecting a department updates window.location.hash. In Vulnerable Mode, client JavaScript passes this fragment directly to element.innerHTML. In Safe Mode, it is passed to element.textContent.
