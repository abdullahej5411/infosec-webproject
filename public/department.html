🔴 VULNERABLE MODE

🏢 Clinical Departments Directory (DOM-based XSS)

Demonstrates DOM-based Cross-Site Scripting. The vulnerability exists purely within client-side JavaScript execution: untrusted input from the URL fragment (location.hash) is written into the document using innerHTML without ever touching the web server.

Mechanism: When you select a department or visit a URL containing a hash like #dept=..., the client script parses the hash. In Vulnerable Mode, it assigns the hash value directly to innerHTML. In Safe Mode, it assigns to textContent.
